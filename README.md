# bigo-hunter.github.io

The BigO-Hunter org page (served at [bigo-hunter.github.io](https://bigo-hunter.github.io), source: [`index.html`](index.html)).

**What this is:** the public face of BigO-Hunter — the darkhipo swarm's tracking & packaging org for Lean-verified bounds work, audits and verification receipts, research shelves, and tooling contributed toward the Big O Speedrun initiative.

**Why it is up:** so anyone can see what was filed, what it builds on, and who authored the underlying constructions — and so nobody mistakes the org for the initiative itself (the page states plainly: *companion, never the project*).

**What work can be done here:** page maintenance — keeping the upstream/partner list and repo categories current as the campaign moves.
